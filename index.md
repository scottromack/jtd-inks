# jtd-inks

Just the Docs on Tailwind v4 and INKs: the same nav tree, search and page features, every
style in straight Tailwind classes, light and dark mode following the reader's system.

The pages in the nav are real Grace Commons pages, copied as test fixtures so every layout
is checked against real content: a page with children (The Corpus), a child with its own
children (Atomic Concepts, Conceptual Compositions), patterns three levels deep (Gift Card,
Cart, Shared Cart), and long method pages (The Method, Execution Contract, Glossary). Their
home is [grace-commons](https://github.com/scottromack/grace-commons); links between them
that point outside this set will not resolve here.
